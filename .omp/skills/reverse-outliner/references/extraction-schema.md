# extraction-schema

`reverse-outliner`가 장면 추출과 판정에 쓰는 필드 정의, 표기, 분류 기준.

## 장면 경계 규칙

- 경계는 원고의 `## N. 제목` 제목 줄 단위로만 잡는다. 제목 줄에서 시작해 다음 제목 줄 앞에서 끝난다.
- 제목 아래에서 시간·장소가 바뀌어도 쪼개지 않는다. 쪼개야만 값이 성립하면 `UNVERIFIABLE`로 표시하고 호출자 확인을 남긴다.
- `***`, 빈 줄, 인용 공문 블록은 장면 경계가 아니다.
- 제목 번호가 건너뛰거나 중복되면 `Limitations`에 적고 번호를 고치지 않는다.
- 장면 ID는 등장 순서로 `S01`, `S02`…를 붙이고 원고 제목을 병기한다(`S01 (1. 첫 출동)`).
- 원고 제목이 없어 경계를 잡을 수 없으면 `boundary-ambiguous`다.

## 필드 정의 (15개)

표의 열은 아래 정의 순서를 따른다. 셀은 짧은 구절로 쓰고 근거는 괄호 안에 장면 ID로 표지한다.

| 필드 | 정의 | 표기 |
| --- | --- | --- |
| `Scene ID` | 등장 순서 식별자 | `S01 (n. 제목)` |
| `POV` | 서술 시점과 관찰자 | `1인칭(나)`, `1인칭(나)+외부삽입`, `외부 시점` |
| `Location` | 사건이 벌어지는 물리적 장소 | 원문 표기의 장소명, 없으면 `미기재` |
| `Time` | 원문에 표기된 시각·경과·순서 표지 | `09:13`, `아홉 시 이십 분`, `미기재`, `없음` |
| `Goal` | 시점 인물이 장면에서 달성하려는 것 | 원문 행동·발화로 드러난 목표만 |
| `Obstacle` | 목표를 막는 대상·조건 | 원문에 제시된 장애, 없으면 `없음` |
| `Choice` | `(S)` 선택지 블록과 실제 선택 | `(S) 항목 → 선택: 굵은 항목`, 블록이 없으면 `없음` |
| `Consequence` | 선택·사건 뒤 즉시 바뀐 것 | 원문 서술 결과 |
| `Information Revealed` | 이 장면에서 독자가 새로 알게 된 것 | `[독자] …` |
| `Information Hidden` | 장면이 언급하지 않거나 감춘 것 | `[인물:이름] …`, `[독자] …`, `[작가] …` |
| `State Change` | 장면 시작과 끝의 상태 차이 | `A → B`, 차이가 확인되지 않으면 `없음` |
| `Next Scene Cause` | 다음 장면을 유발한 원인 | 원문 서술 원인, 없으면 `없음` |
| `삭제 가능성` | 삭제해도 뒤 구조가 유지되는가 | `독립`, `부분`, `불가` |
| `인과 연결 강도` | 앞 장면 결과가 원인으로 명시되는가 | `강`, `약`, `단절` |
| `중복 장면 여부` | 같은 기능이 반복되는가 | `고유`, `부분 중복`, `중복` + 대응 `Scene ID` |

- `Goal`과 `Obstacle`에 작가 의도나 설정 추정을 쓰지 않는다. 문장과 행동으로 확인된 것만 쓴다.
- `Choice`의 선택 표시는 굵은 항목이다. 선택 표시가 없으면 선택지를 나열하고 `선택 미표시`를 덧붙인다.

## 판정 기준

### 삭제 가능성

- `독립`: 장면을 빼도 앞뒤 장면의 인과·정보·상태 변화가 그대로 성립한다. 그 장면만의 정보 공개가 없다.
- `부분`: 빼면 손실이 있지만 다른 장면이 같은 사건을 대신 전달한다. 잃는 정보를 함께 적는다.
- `불가`: 빼면 다음 장면의 원인이나 인물 상태가 성립하지 않는다. 무효가 되는 뒤 장면 ID를 적는다.
- 판정은 구조에서 하는 일 기준이며 문장 품질은 보지 않는다.

### 인과 연결 강도

- `강`: 앞 장면의 선택·결과가 다음 장면의 도입부나 행동 이유로 명시된다.
- `약`: 순서상 이어지지만 원인 문장이 없다. 독자가 순서로만 연결한다.
- `단절`: 앞 장면과의 인과가 없거나 다른 사건에서 갑자기 시작한다.

### 중복 장면 여부

- `고유`: 같은 목표·장애물·정보 공개가 다른 장면에 없다.
- `부분 중복`: 목표나 정보 공개 중 일부가 겹친다. 겹치는 범위를 적는다.
- `중복`: 목표·장애물·정보 공개·상태 변화가 다른 장면과 사실상 같다. 대응 `Scene ID`를 적는다.
- 근거는 `Goal`, `Obstacle`, `Information Revealed`, `State Change` 네 값의 비교다.

## `미기재`와 `없음`

- `미기재`: 원문에서 값을 확인할 수 없다. 추측으로 채우지 않고 그대로 남긴다. 구조 갭 판정에서 근거 부족으로 다룬다.
- `없음`: 요소가 원문에 존재하지 않는 것이 확인된 상태다.
  - `Choice`: 장면에 `(S)` 블록이 없다.
  - `Obstacle`: 목표를 막는 대상·조건이 서술되지 않았다.
  - `State Change`: 장면 시작과 끝의 상태가 텍스트상 같다.
  - `Next Scene Cause`: 원고가 끝났거나 다음 장면이 없다.
- 구분 규칙: 구간을 끝까지 읽었고 요소가 없으면 `없음`, 구간이 잘렸거나 판독할 수 없으면 `미기재`다.
- 둘 다 근거를 괄호로 병기한다. 근거 없는 `없음`은 쓰지 않는다.

## 구조 갭 4종

| 갭 | 판정 기준 | 예 |
| --- | --- | --- |
| 고아 장면 | 앞 장면의 결과로 시작하지 않고 뒤 장면을 유발하지도 않는다. `인과 연결 강도`가 `단절`이고 `Next Scene Cause`가 `없음`이거나 다른 사건을 가리킨다. | 예: 앞 장면과 무관한 조사 보고로 시작하고 다음 장면도 다른 원인으로 진행 |
| 무변화 장면 | `State Change`가 `없음` 또는 `미기재`다. | 예: 사건은 있으나 인물·자원·지식·관계가 장면 전후로 같음 |
| 중복 장면 | `중복 장면 여부`가 `중복`이다. 같은 목표·장애물·정보 공개가 반복된다. | 예: 두 장면이 같은 선택지를 다른 표현으로 반복 |
| 끊긴 인과 | `Next Scene Cause`가 있는데 다음 장면의 `Goal`·`Obstacle`·도입부 어디에도 반영되지 않는다. | 예: 회사 전체 호출이 다음 장면에서 아무 결과를 만들지 않음 |

- 예 열은 판정 형식 예시이며 특정 원고의 실제 판정이 아니다.
- 반대 예: `S01`은 `State Change`가 `관찰자 → 출동 준비`이므로 무변화 장면이 아니고, `S02`는 `Next Scene Cause`가 `S01`의 공문으로 이어지므로 끊긴 인과가 아니다.
- 각 갭 항목에 `Scene ID`, 판정 근거(장면 제목), 영향받는 뒤 장면을 적는다.
- 갭이 없으면 `없음`으로 쓰고, 판정하지 못한 장면은 `UNVERIFIABLE`로 표시한다.

## 의도 대비 비교 절 형식

호출자가 의도 구조를 제공한 경우에만 만든다. 제공되지 않으면 절 자체를 만들지 않는다.

| 항목 | 의도한 이야기 | 텍스트의 이야기 | 차이 |
| --- | --- | --- | --- |
| S02 목표 | 의도 구조 원문 (출처: 호출자 메모 n행) | 원문 요약 (S02, 41–127행) | 의도에만 있음 |
| 정보 공개 | 의도 구조 원문 | 원문 요약 | 어긋남 |

- 각 행은 의도 쪽 근거와 텍스트 쪽 근거를 모두 가진다.
- 차이 유형은 `의도에만 있음`, `텍스트에만 있음`, `어긋남`, `판단 불가`만 쓴다.
- 의도 구조가 일부 장면만 덮으면 덮인 범위를 `Scope`에 적고 나머지는 비교하지 않는다.
- 의도와 다르다는 사실을 결함으로 단정하지 않는다. 차이 기록까지가 이 스킬의 범위다.

## 1인칭 정보 경계 표기

`POV`가 1인칭이면 서술자가 보고 들은 것만 장면 값이 된다. 작가 지식·독자 지식·인물 지식은 분리해서 적는다.

- `POV` 표기:
  - `1인칭(나)`: 서술자가 장면 안에 있고 관찰 가능한 범위만 서술된다.
  - `1인칭(나)+외부삽입`: 서술자가 관찰할 수 없는 타인 행동·내부 생각이 서술된다. 삽입 문장의 위치를 장면 제목으로 병기한다.
  - `외부 시점`: 서술자가 장면 인물이 아닌 경우.
- `Information Hidden` 표기:
  - `[인물:이름] X`: 인물은 알지만 독자에게 아직 공개되지 않았다.
  - `[독자] X`: 독자는 봤지만 장면 인물은 모른다. `[인물:이름]`과 구분한다.
  - `[작가] X`: 원장에만 있고 원고 어디에도 표시되지 않았다.
  - 예: 루의 `hiddenIdentity`(도래한 괴수의 일부), 최 반장의 `hiddenActivity`(감시 보고서), 강두식-루시퍼 분리 인과는 공개 전까지 `[작가]` 범주다.
- 규칙:
  - 인물 지식으로 승격하려면 그 인물이 문장·행동으로 알게 된 근거가 원문에 있어야 한다.
  - 서술자가 모르는 사실을 1인칭 문장의 판단 근거로 쓰지 않는다. 위반이 보이면 `[CONFLICT]`로 표시한다.
  - `Information Hidden` 값은 원장·원고에서 확인된 것만 쓰고 새 비밀을 만들지 않는다.
