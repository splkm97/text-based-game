# 구조 진단 기준

구조 진단의 판정 기준, 검출 신호, 절차를 정의한다. 모든 위치는 `파일:줄`로 표기하고, 사실 범주는 `[FACT]`, `[INFERENCE]`, `[HYPOTHESIS]`, `[CONFLICT]`로 구분한다. 정본에 없는 내용은 검출 근거로 쓰지 않는다. 취향 차이는 결함으로 세지 않는다.

## 1. 삭제 테스트

절차:

1. 대상 장면의 사건, 대사, 선택, 획득 정보를 목록화한다.
2. 장면을 제거한 상태에서 이후 인과를 재구성한다. 앞 장면과 뒤 장면을 직접 연결해 본다.
3. 뒤 장면에서 성립하지 않는 요소를 모두 기록한다. 요소마다 대체 장면이 있는지 확인한다.
4. 결과를 등급으로 매긴다.

| 결과 | 등급 |
|---|---|
| 삭제하면 이후 장면·선택·결말이 성립하지 않거나 다른 경로가 필요하다. | `Essential` |
| 삭제해도 성립하지만 핵심 갈등·관계의 강도가 약해진다. | `Contributing` |
| 삭제해도 이후가 거의 그대로이고 대체 장면이 있다. | `Optional` |
| 삭제해도 이후가 완전히 동일하고 같은 기능을 다른 장면이 이미 수행한다. | `Redundant` |

`Redundant` 등급은 반복 검사 결과와 함께 기록한다.

## 2. 변화 테스트

절차:

1. 장면 시작 상태와 종료 상태를 쓴다: 인물 관계, 소유·자원, 지식, 세계 상태, 위험 수준.
2. 시작과 종료를 비교해 변한 항목을 센다.
3. 변한 항목이 다음 장면의 전제가 되는지 확인한다.

판정:

- 상태·관계·지식·위험 중 하나 이상이 바뀌고 그 변화가 다음 장면의 전제가 되면 `변화 있음`.
- 변화가 있어도 다음 장면의 전제가 아니면 `국소 변화`.
- 모든 항목이 같으면 `변화 없음`. `Essential` 등급 근거가 없으면 문제 후보다.

## 3. 검사 항목 판정 기준

| 검사 항목 | 판정 기준 | 검출 신호 |
|---|---|---|
| 인과관계 | 각 사건의 원인이 이전 장면이나 원장 규칙에서 확인된다. | 원인 없이 결과만 서술, 직전 장면과 모순, 인물이 알 수 없는 정보로 행동 |
| 장면 필요성 | 삭제·변화 테스트에서 `Essential` 또는 `Contributing` 근거가 있다. | `Redundant` 등급, `변화 없음` |
| 반복 | 같은 대립 축·이해관계·결과가 2회 이상 나오지 않는다. | 형태만 바뀐 갈등, 같은 정보의 재전달, 같은 선택 재질문 |
| 갈등 강도 | 갈등이 인물의 대응을 강제하고 실패 가능성을 가진다. | 갈등 없는 통과, 대응하지 않아도 되는 위협 |
| 선택의 비용 | 선택마다 포기하는 것과 감수하는 위험이 구체적이다. | 비용 없는 선택, 모든 선택이 같은 결과, 되돌릴 수 있는 선택 |
| 우연 의존 | 사건 발생·해결의 계기가 사전 준비 없이 등장하지 않는다. | 직전 장면 도입 장치, 준비 없는 구출, 시간 맞춘 조력 |
| deus ex machina | 해결이 인물의 선택과 준비된 수단으로 이루어진다. | 외부 존재의 일방 해결, 미준비 능력 각성 |
| 중반부 정체 | 중반부에 새 갈등·새 정보·stakes 변화가 계속 발생한다. | 같은 위치·상대의 반복, 목표 없는 장면 연속, 시간 경과만 서술 |
| stakes 변화 | 진행에 따라 잃을 것과 위험 범위가 변한다. | 초반과 중반 stakes 동일, 위험 상승 없는 사건 추가 |
| climax 준비 | 클라이맥스의 수단·대립·비용이 이전 장면에 배치되어 있다. | 클라이맥스 전용 장치의 첫 등장, 대립 인물의 동기 미제시 |
| character agency | 문제의 악화와 전진이 인물의 선택에서 나온다. | 인물이 반응만 함, 조력자가 결정을 대신함, 선택과 결과의 무관 |
| setup/payoff | 배치된 준비가 회수되고, 회수되는 장치에 준비가 있다. | 미회수 setup, 미준비 payoff, 회수 시점의 과도한 지연 |

## 4. 핵심 질문 7개 적용표

| 질문 | 적용 대상 | 문제 신호 |
|---|---|---|
| 이 장면을 삭제하면 이후 이야기가 달라지는가? | 모든 장면 | `Redundant`, `변화 없음` |
| 이 장면에서 무엇이 변하는가? | 모든 장면 | 관계·자원·지식·위험이 모두 불변 |
| 문제가 인물의 선택으로 악화되는가? | 갈등 장면, 전환점 | 악화가 외부 사건·조력자·규칙에만 기인 |
| 갈등이 외부 사건만으로 발생하는가? | 갈등 도입부 | 인물의 목표·욕망이 갈등에 관여하지 않음 |
| 해결책이 이전에 준비되었는가? | 해결 장면 | 해결 수단이 같은 장면에서 처음 등장 |
| 주인공이 아닌 존재가 문제를 해결하지 않는가? | 해결·구출 장면 | 조력자·히어로·시스템이 결정적 행동을 대신함 |
| 같은 갈등이 형태만 바뀌어 반복되는가? | 중반부 연속 장면 | 대립 축·이해관계·결과가 동일 |

## 5. 우연 의존과 준비된 복선의 구분

1. 해결에 쓰인 장치·수단·정보를 식별한다.
2. 그 장치의 성질·존재·획득 경로가 문제 제기 이전 장면이나 원장에 있는지 검색한다.
3. 준비 위치가 있으면 `준비된 장치`다. 준비가 인물의 행동으로 획득되었는지도 확인한다.
4. 준비 위치가 없거나 같은 장면·직전 장면에서 처음 등장하면 `우연 의존` 후보다. `deus ex machina`는 그 장치가 인물의 선택 없이 문제를 해소할 때만 적용한다.
5. 준비 위치가 있어도 인물이 그 사실을 알 수 없었다면 인물 지식 위반을 별도 후보로 기록한다.

## 6. 반복 갈등 판정

- 장면마다 대립 축, 양측 이해관계, 이번 결과를 표로 적는다.
- 세 항목이 모두 같으면 `반복`이다.
- 이해관계와 결과가 같고 상대만 바뀌면 `형태만 바뀐 반복`이다.
- 결과가 누적되어 새 상태(관계 파탄, 자원 소진, 책임 전가, 신뢰 상실)를 만들면 `변주`로 인정하고 반복으로 세지 않는다.
- 반복 후보에는 반복 횟수와 각 위치를 적는다.

## 7. 수정 방향 A/B 제약

- A/B는 무엇을 바꿀지의 방향 서술만 쓴다. 대사·문장·수정문 자체는 쓰지 않는다.
- 정본 위반 금지: 원장에 확정된 규칙·성질·인물 지식·공개 범위를 깨는 방향은 쓰지 않는다.
- 정본 위반이 불가피한 해결만 가능하면 그 방향을 `[CONFLICT]`로 표시하고 비고에 사람 결정이 필요함을 적는다.
- A와 B는 서로 다른 축이어야 한다. 같은 축의 미세 변형 2개는 쓰지 않는다.
- 새 사실·새 장치를 도입하는 방향은 `[HYPOTHESIS]`로 표시한다.
- 각 방향에 조정 범위를 적는다: 단일 장면 국소 수정, 연쇄 장면 조정, 장면 추가·삭제, 순서 재배열.

## 8. 심각도 판정표

| 심각도 | 기준 | 예 |
|---|---|---|
| `Critical` | 이야기 성립이 실패한다. 삭제·재배열 없이는 이후가 성립하지 않는다. | 인과 단절, 해결 불가, 주인공 무행동, 결정의 결과 소실 |
| `Major` | 구조 결함이 있다. 수정 없이는 갈등·비용·준비가 약하다. | 동기·비용 부재, 준비 없는 해결, stakes 정체, 반복 갈등, 미회수 setup |
| `Minor` | 국소 문제다. 흐름만 방해한다. | 정보 재전달, 도입부 지연, 위치 표기 불일치, 대사 중복 |

- `Critical`/`Major` 후보에 근거 위치가 없으면 `Minor`로 낮추거나 `UNVERIFIABLE`로 표시한다.
- 같은 장면의 여러 `Minor`가 같은 원인에서 나오면 하나의 `Major` 후보로 묶는다.
- 심각도는 결함의 크기이며 취향 평가가 아니다. 정본에 근거가 있는 선택은 결함으로 세지 않는다.
