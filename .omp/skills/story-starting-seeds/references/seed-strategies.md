# 시드 기법 목록

출처: Hannah Nicklin, *Writing for Games: Theory and Practice*(CRC Press, 2022), 3부 "Tools for Starting"(pp.183-186) 및 저자 스튜디오 공개 발췌 — https://gutefabrik.com/writing-for-games-excerpt-1/. 아래는 각 기법의 작동 방식을 의역한 것이고, 저자가 붙인 기법명만 원문대로 쓴다.

## 시드 기법 아홉

| 기법 | 작동 방식 | 매체 |
|---|---|---|
| **Collage** | 잡지를 잘라 붙여 인물·장소·세계를 만든다 | 시각 |
| **Redacted** | 신문·잡지·책의 문장과 단어를 검게 지워 쓸 만한 대사나 문장이 나올 때까지 지운다 | 시각+문자 |
| **'Like X but Y'** | 기존 이야기·장르·장소·인물을 부딪혀 붙인다. 인물을 다른 자리에 옮기고, 이름과 세부를 바꿔 새것이 될 때까지 밀어붙인다 | 문자 |
| **메모장의 이미지·조각·순간** | 머리가 스스로를 즐겁게 한 순간마다(한 줄, 기억, 이미지) 적어 두는 습관을 들인다 | 문자 |
| **Morning Pages / 의식의 흐름** | 아무 목적 없이 쓴다. 막히면 'and'를 반복해도 좋다. 1분·3분·5분 타이머로 쓰고, 주말에 모아 훑으며 쓸 만한 줄·이미지·주제를 건진다 (Julia Cameron의 기법) | 문자 |
| **Cuttings** | 신문 기사, 트윗 스크린샷 같은 흥미로운 조각을 스크랩북이나 폴더에 모은다. 정리 방식은 자기 마음대로 | 혼합 |
| **비스킷 통 / 조각 책** | 이미지·단어·주제를 통에 넣고, 영감이 필요할 때 꺼낸다 | 혼합 |
| **Exquisite corpse** | 헌 책·엽서·사진에서 인물 조각을 모은다. 머리·옷·배경을 백 개쯤 잘라 섞어 붙이다 보면 목소리가 들리는 인물을 만난다 | 시각 |
| **Oblique Strategies** | Brian Eno의 카드 뭉치에서 한 장을 뽑아 막힌 생각을 뒤집는다 | 문자 |

고르는 기준: **매체가 섞이게** 3~5개. 저자는 자기 실천이 형태(form) 중심이라고 밝히면서, 맞지 않으면 다른 접근을 보라고 세 권을 든다 — Lynda Barry *What It Is*(시각적인 사람), Michael Atavar *How to Be an Artist*(저자와 유사하지만 더 많이), Julia Cameron *The Artist's Way*(더 영적이고 직관 구동).

## 단어 시드

저자는 워크숍용으로 단어 시드를 인쇄해 작은 통에 넣고 쓴다. 목록은 약 25개이고, 예시는 이렇다(원문에서 몇 개만 옮김):

- the sea
- a sad fox
- an antique suitcase, locked
- a bird that fell from the nest
- seven bad mistakes

전체 목록은 책에 있다. 저자가 붙인 주의: 이건 **예시일 뿐**이고, 자기 지역·동료·정체성에 맞게 바꾸라고 적는다. 뽑아서 맞지 않으면 되돌려 놓아도 된다.

## 이 목록을 쓰는 법

1. 3단계에서 기법을 3~5개 고른다(시각 하나 + 문자 하나 이상).
2. 4단계에서 기법마다 시드를 최소 하나 만든다. 재료가 무엇이었는지 함께 적는다.
3. 6단계에서 기법마다 짧은 형식 하나를 빠르게 시작한다.
4. 7단계에서 최선/탈락을 판정한다. 탈락은 실패가 아니라 그 사람에게 맞지 않는다는 정보일 뿐이다.
