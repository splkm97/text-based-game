# 모험가 이야기

중세 판타지 세계를 떠도는 모험가가 되어 사건을 고르고, 주사위를 굴리고, 결말을 모으는 텍스트 로그라이크입니다. 휴대폰 브라우저에서 바로 실행되는 PWA이고, 모든 데이터는 기기 안에만 저장됩니다.

이 프로젝트는 텍스트 로그라이크 장르에 대한 개인 오마주입니다. 사건, 결말, 이름, 픽셀 아트는 전부 이 저장소에서 새로 만든 창작물이며, 어떤 상용 게임의 텍스트나 자산도 포함하지 않습니다.

## 실행

Node 24와 pnpm이 필요합니다. 저장소에 `.nvmrc`가 있습니다.

```sh
nvm use
pnpm install
pnpm dev --host
```

터미널에 나오는 `Network` 주소를 같은 Wi-Fi의 휴대폰에서 열면 됩니다.

오프라인 동작과 홈 화면 설치는 빌드 결과물에서만 켜집니다. `localhost` 또는 https에서만 서비스 워커가 등록됩니다.

```sh
pnpm build
pnpm preview --host
```

## 게임 방법

1. **캐릭터 생성.** 이름, 출신 3종 중 하나, 특성 10종 중 하나를 고릅니다. 여정(서브 스토리) 3종을 켤 수 있고, 어려움 모드를 선택할 수 있습니다. 여섯 능력치(힘, 민첩, 지능, 카리스마, 건강, 지혜)는 각각 4에서 시작하며 18포인트를 나눠 담습니다. 한 능력치의 시작 상한은 10입니다.
2. **사건.** 하루에 사건 하나가 나옵니다. 선택지는 능력치, 아이템, 골드, 특성, 이전 선택에 따라 열리거나 닫힙니다. 닫힌 선택지에는 이유가 함께 표시됩니다.
3. **판정.** 판정은 20면체 주사위에 능력치를 더해 목표치와 비교합니다. 20은 항상 성공, 1은 항상 실패입니다.
4. **전투.** 매 라운드 주사위를 굴립니다. 20이면 즉시 승리, 1이면 방어를 무시한 두 배 피해를 받습니다. 도주는 민첩 판정입니다.
5. **성장.** 경험치가 10 오를 때마다 능력치 포인트를 받습니다. 경험치가 100에 닿으면 모험이 끝납니다. 체력이나 정신력이 0이 되어도 끝납니다.
6. **결말과 기록.** 출신마다 좋은 결말과 나쁜 결말이 하나씩, 여정마다 결말이 하나씩 있습니다. 결말, 마주친 몬스터, 얻은 아이템은 도감에 쌓이고 점수는 랭킹에 남습니다.

저장은 매 사건 뒤 자동으로 됩니다. **불러오기**를 3회 이상 쓰면 그 모험은 랭킹에서 제외됩니다. 타이틀의 **이어하기**는 횟수를 세지 않습니다.

## 콘텐츠 규모

| 항목 | 수 |
|---|---|
| 사건 | 84 (공통 51, 출신 18, 여정 15) |
| 결말 | 12 |
| 아이템 | 40 |
| 몬스터 | 20 |
| 특성 | 10 |

## 개발

```sh
pnpm verify   # 타입 검사, 린트, 테스트
pnpm build    # 정적 빌드와 서비스 워커 생성
```

| 폴더 | 역할 |
|---|---|
| `src/engine` | 규칙. 순수 함수만 있으며 React와 콘텐츠를 모릅니다. |
| `src/content` | 데이터. 사건, 아이템, 몬스터, 특성, 출신, 여정, 결말. |
| `src/art` | 16×16 픽셀 스프라이트와 SVG 렌더러. |
| `src/store` | 상태와 저장. zustand, zod로 검증한 localStorage. |
| `src/ui` | 화면. React 19, Tailwind 4. |
| `src/editor` | 콘텐츠 편집기 화면. 개발 모드에서만 실행됩니다. |
| `tools/content-editor` | 편집기의 저장 서버. Vite 개발 서버 플러그인입니다. |

콘텐츠 편집기가 있습니다. `pnpm dev`를 실행하고 `http://localhost:5173/__content`을 엽니다. 사건과 결말의 글을 화면에서 고치고, **저장**을 누르면 `src/content`의 소스 파일이 그대로 바뀝니다. 이 페이지는 개발 모드에서만 열리며 빌드 결과물에는 들어가지 않습니다. 편집기 안의 시험 플레이는 메모리에만 저장되므로 실제 저장 파일, 도감, 랭킹을 건드리지 않습니다.

기술 스택은 Vite 8, React 19, TypeScript 7, Tailwind 4, Zustand 5, zod 4, Vitest 5, Biome 2입니다. 글꼴은 Galmuri11이며 SIL Open Font License 1.1로 배포됩니다. 색은 PICO-8 16색 팔레트만 씁니다.
