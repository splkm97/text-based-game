## 역산 좌표

출발점은 종결 문장이다 — `settings.characters.dusik.trueEnding`:
"협회가 도래를 불렀다는 사실을 밝혀내 배상금 누명을 벗고 당당하게 다시 히어로가 된다."

결말 직전에 참이어야 하는 상태를 역으로 분해하면 네 칸이 된다.

| 칸 | 참이어야 하는 상태 |
|---|---|
| ① | 협회가 도래를 불렀다는 사실이 **문서로** 확인된다 |
| ② | 그 문서가 강두식의 배상 청구와 같은 계보에 있다(청구 근거가 사후 편성임이 드러난다) |
| ③ | 확인된 내용이 공적 절차·채널에 제출된다 |
| ④ | 제출의 결과로 강두식이 재등록 자격을 회복한다 |

모든 후보는 "계기 → 접근 → 검증 → 폭로" 네 칸의 연쇄로 쓴다. 괄호 안은 각 칸이 위 ①~④ 중 무엇을 채우는지다.
역순이므로 실제 집필 순서는 폭로(③④)에서 계기로 거슬러 올라간다.

### 16. 재등록을 거부한다

폭로가 성공한 뒤 두식은 히어로 재등록을 거부하고 회사 명의 현장 자격으로 남는다. (계기 ④ → 접근 ③ → 검증 ④ → 폭로 ④)

- **선택:** 재등록을 권할지, 거부를 회사 기록으로 확정할지.
- **악화:** 권하면 두식의 자리가 다시 협회 등급표 안으로 들어가고, 확정하면 현장 통제 근거가 회사 명의로만 남는다.
- **근거:** `settings.characters.dusik.trueEnding`; `settings.association.heroRegistrationGrades`;
  `settings.company.fieldDispatch`.
- **범주:** `[CONFLICT]` — 종결 문면 "다시 히어로가 된다"와 충돌한다. 대안: 재등록하되 등급을 스스로 고르는
  경로로 바꾸면 문면을 유지한다.
- 거리: 3

### 17. 등급 방송이 먼저 규정한다

문서가 진짜여도 협회 등급 방송이 먼저 "무자격자 주장"으로 규정하면 문서는 효력을 잃는다. 폭로의 승리가 아니라
규정을 되돌리는 싸움이 남는다. (계기 ① → 접근 ③ → 검증 ④ → 폭로 ③)

- **선택:** 방송에 정정을 요구할지, 방송이 잊힐 때까지 기다릴지.
- **악화:** 정정 요구는 협회 채널을 한 번 더 쓰게 하고, 기다리면 두식의 압류가 그대로 진행된다.
- **근거:** `settings.association.appearanceChannels`; `settings.association.monsterAlertGrades`;
  `settings.characters.ru.publicExposure`.
- **범주:** `[INFERENCE]` — 방송 채널은 정본이 허용한 등장 경로다.
- 거리: 3

### 18. 회사가 공범이었다

회사는 7년간 협회 서식과 청구 체계를 그대로 받아 썼다. 두식의 누명을 벗기려면 회사가 서명한 과거 문서가
함께 문제가 되어야 한다. (계기 ② → 접근 ① → 검증 ② → 폭로 ③)

- **선택:** 회사 과거 서명을 함께 제출할지, 두식 건만 떼어낼지.
- **악화:** 함께 내면 협회 발주가 끊겨 회사가 파산 위험에 서고, 떼어내면 사슬이 끊겨 기각된다.
- **근거:** `settings.company.history`; `settings.company.coreMission`; `settings.company.responsibilities`;
  `prototype/game-mechanics.md` 「잔여 결정」 5(파산 엔딩 전제).
- **범주:** `[CONFLICT]` — 회사가 협회 체계에 가담했다는 신규 사실은 `company.history`의 중립 서술과 긴장한다.
  대안: 회사는 가담이 아니라 **서명만 했다**로 낮춰 서술하면 충돌이 사라진다.
- 거리: 3

### 19. 증인을 쓰지 않고 이긴다

①의 마지막 칸을 루의 증언으로 채우면 이기지만 루가 파멸한다. 두식은 증인 없이, 문서만으로 그 칸을 채우는
경로를 찾는다. (계기 ① → 접근 ① → 검증 ② → 폭로 ③)

- **선택:** 루에게 증언을 요청할지, 문서만으로 버틸지.
- **악화:** 요청하면 루의 정체가 공적 기록으로 남고, 버티면 사슬이 약해 기각 위험이 커진다.
- **근거:** `settings.characters.ru.hiddenIdentity`(비밀); `settings.characters.ru.knowledge`;
  `settings.characters.dusik.secretCausality`(작가 지식).
- **범주:** `[CONFLICT]` — 결말이 요구하는 "밝혀낸다"를 증인 없이 달성해야 하므로, 증거의 결정력이 문서 쪽에
  더 실려야 한다. 대안: 시퍼(생체 증거)를 문서와 교차시킨다.
- 거리: 3

### 20. 협회 절차 안으로 들어간다

재등록 대신 두식이 협회 심사 절차의 심사 보조 자격으로 들어가 안에서 서식을 뒤집는다. (계기 ④ → 접근 ① → 검증 ② → 폭로 ③)

- **선택:** 절차 안으로 들어갈지, 밖에서 이의를 반복할지.
- **악화:** 들어가면 등록 등급표에 다시 오르고, 밖에 있으면 서식 개정에 계속 뒤진다.
- **근거:** `settings.association.heroRegistrationAuthority`; `settings.association.history`;
  `settings.company.responsibilities`.
- **범주:** `[HYPOTHESIS]` — 제도 내부 진입은 새 제도 제안이다. 비밀 게이트와 충돌하지 않는다.
- 거리: 3
